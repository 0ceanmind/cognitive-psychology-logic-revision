# Cognitive Psychology and Logic — Interactive Revision

An interactive, large-screen revision presentation and mock exam for **ATM00201 Cognitive Psychology and Logic** (Chapters 1–4).

- `index.html` — the presentation. Navigate with → / ← (or a clicker), `M` contents, `F` fullscreen, `L` light/dark, `B` blackout, `E` mock exam.
- `exam.html` — mock exam: 10 MCQs + 5 short definitions drawn at random from a bank built on the lecture notes.

Developed by **Faisal Albusaidi**.

All content is taken from the module's lecture decks. No build step: plain HTML, CSS and JavaScript.
